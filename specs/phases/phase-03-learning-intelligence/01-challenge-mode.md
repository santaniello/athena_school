# Phase 3.1 — Challenge Mode

## Goal

User receives a problem generated by the LLM, answers it, and gets structured feedback.

## Domain

```go
type ChallengeSession struct {
    ID        string
    Topic     string
    Problem   string
    Answer    string
    StartedAt time.Time
    EndedAt   time.Time
}
```

## Tasks

- [ ] `internal/domain/challenge/` — `ChallengeSession` struct + rules
- [ ] LLM generates a problem tailored to `UserProfile` (area, level, topic)
- [ ] UI: problem display area, answer text area, submit button
- [ ] On submit: answer sent to Evaluation Engine (see 3.2)
- [ ] Session persisted to `sessions` table with `mode = "challenge"`

## Acceptance Criteria

- User selects a topic and starts a challenge session
- A problem appropriate to the user's level and area is displayed
- Submitting an answer sends it to the evaluation flow
- Session and messages are saved to SQLite on completion
