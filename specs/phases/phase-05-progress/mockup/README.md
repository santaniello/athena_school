# Progress — Approved Mockup

Visual reference for Phase 5, approved on 2026-11-23. It follows the specs of this phase (scores,
status rule, insight states, evolution chart) with fictional data, and the app's own theme (warm
dark background, gold accent, Cinzel headings, Nunito body).

- **Interactive version:** https://claude.ai/artifact/8ADzEMmFVyFDVbUozFNmtZ (private to the owner)
- **Source:** [`progress.dc.html`](progress.dc.html), a Design Component file. It needs the canvas
  runtime (`support.js`) and does not open on its own in a browser; read it for layout, copy and
  the sample data.

## States it shows

| Topic | Demonstrates |
|---|---|
| Cache | Quiz 85% (mean of the latest attempts 90 and 80), Arch Lab 63% (diagram 85, defense 40, failed) → Needs reinforcement; stale insight |
| Paralelismo | Quiz 61% below the minimum → Needs reinforcement; no insight yet, Generate button |
| Mensageria | Quiz 70 → 88 and a passed lab → Improving; fresh insight |
| Observabilidade | Insufficient evidence; no chart, no insight button |
| Concorrência / Collections (Java) | Improving / Stable |

The mockup is a reference, not a contract: where it and the specs disagree, the specs win.
